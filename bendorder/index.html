Support and Privacy — BendOrder
Effective: 2026-10-28

SUPPORT
For help with BendOrder, email codetea@163.com. Please include the iOS version, the app version and a short description of what happened. We answer support requests in the order they arrive.

PRIVACY
BendOrder is designed to work on the device. Documents, photos, measurements, snippets and settings created in the app are stored in the app's local container. The developer does not operate an account system, cloud database, remote sync, analytics SDK, advertising SDK or tracking technology, and does not receive the content you create.

Features that need a system permission (for example the microphone, photo library, local network or notifications) use it only for the feature you started. The optional in-app purchase is processed by Apple through StoreKit; the developer does not receive payment details.

Removing the app and its data from the device removes the locally stored content. The developer holds no remote copy.
